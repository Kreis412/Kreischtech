# Reporting and field workflow update

- Company overview defaults to year to date with matching prior-year cash comparisons. Cash receipts remain explicitly separate from earned/invoiced revenue.
- Current project estimates show estimated profit, return on cost and margin; unresolved inputs remain provisional. No bank sync, invoice accounting, actual net profit or contracted backlog is claimed.
- Materials & estimate → Discoveries to price links observations and confirmed findings to unpriced suggestions. Repeat requests do not duplicate items. Source revisions flag another review. Linking does not authorize work; excluded items require a reason.
- Site photos stages originals in IndexedDB before sending them. Failed uploads remain under Waiting to upload on the same browser/account/company/project. Retry uses an idempotency key, including after an uncertain server response. Server checks the authenticated company and user before accepting retries.
- The queue needs browser storage and an already-open project. It is not a fully offline app, background sync or a backup. Keep originals; clearing browser data/private-mode expiry/storage eviction can remove queued photos. Successful uploads clear their local pending copies. Teammates see saved photos after refreshing.
- Assisted account recovery is available through Forgot password. Existing passwords and sign-in behavior remain unchanged.

## Operator recovery

Verify the requesting account owner through a trusted channel before using Render Shell. Set DATA_DIR to the persistent account database directory (the hosted service uses /var/data), then run:

    node recover-account.mjs account-email

This issues one random code, valid for 30 minutes, stored only as a hash. Share privately with the verified owner. They enter their own new password and submit the recovery form. Never use pilot invitation codes for recovery, log plaintext passwords, or reset an unrelated tester. Successful recovery invalidates the owner's existing sessions and codes without altering memberships or projects. No automatic email delivery is implemented.

## Validation

Run `npm ci` then `npm test`; start locally with `npm start` (Node 22.14+).
Automated checks cover comparison dates/leap years, estimated returns, source review/revisions/isolation, upload deduplication and workspace binding, and recovery expiration/reuse/concurrency/session revocation.
Browser check: local test photo saved; with local server stopped, the pending original survived reload after restart and uploaded through Retry. Financial and estimate screens checked at 390px width. No live customer test data or paid AI calls used.
